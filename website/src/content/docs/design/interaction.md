Два окна. Pre-main: ширина 460, высота по панели (обновление **460×316** до показа, потолок 700). Главное — 1024×640: колонка слева **253 px** и дальше **220–340 px** по ширине окна. Исходная диаграмма лежит в `docs/design/interaction.mmd`. Здесь те же ветки текстом: плагинов диаграмм на сайте нет.

## Счастливый вход

Обновление → вход → при необходимости код из почты или код из приложения → главное окно → **ИГРАТЬ**.

`-Dlauncher.mock2fa=none` пропускает второй фактор. На live второй фактор решает ответ клиента EXBO, не это свойство.

Предложенное обновление лаунчера на live отклоняется, пока нет закреплённого публичного ключа релиза: файл не пишется, окно показывает «Обновление лаунчера отклонено: нет проверенной подписи.». Без предложения проверка заканчивается и открывается вход. Mock доигрывает таймер и идёт на вход.

## Регистрация

Вход → **Создать** → возраст не меньше 18 → форма → снова вход с ником и notice «создан» → пароль. Это ветка mock.

Ошибка формы оставляет вас на регистрации. «← Назад» возвращает на возрастной гейт с той же датой. Возраст меньше 18 показывает отказ и остаётся на гейте.

На live цепочка доходит до формы и останавливается: `RegisterError.NOT_SUPPORTED`, текст «Этот лаунчер не создаёт аккаунт. Создайте его на сайте STALZONE.». Запроса регистрации нет. Ветка mock выше не менялась.

## Ошибки входа

Пустой логин, пароль `wrong` и код из приложения `000000` показывают поле или тост и не открывают главное окно. Код из почты `000000000` тоже остаётся в pre-main.

## Игра

**ИГРАТЬ** или меню **⋯** ведёт в состояния клиента: готово, загрузка, пауза, запущена, проверка.

Меню **⋯** на `main`: проверить файлы, открыть папку игры, настройки игры, переустановить, удалить. Переустановка, удаление и проверка уже запущенной игры сначала спрашивают подтверждение. Пока операция идёт, **ИГРАТЬ** неактивна. На mock операции — таймеры `MockUpdateService`.

Папка открывается только внутри `gameRoot`. Путь выше корня отклоняется. Если нет и корня, ничего не открывается, в stderr пишется WARNING.

Онлайн в списке игр на mock по умолчанию слегка меняется каждые 10 с. `-Dlauncher.onlineTickMs=0` держит 1284. В автотуре всегда 0.

## Оболочка и туннель

Логотип масштабируется с колонкой, подпись игры остаётся в строке. Колонка настроек заполняет область контента, потолок 820 px снят. На 1280 px страница туннеля на всю ширину.

Заголовок, панель действий и карточки групп — отдельные блоки. Колонки «До вас» / «Пинг» и переключатели блока на месте. На 900×580 и 1280×760 подписи помещаются целиком.

Мок показывает каталог из classpath (`servers-ru.json`, `servers.json`, фикстура NEA) и за списком в сеть не ходит. «Загружаю группы…», «Не удалось загрузить группы» и пустой каталог — разные карточки. У ошибки есть «Повторить». «Отмена» подтверждения блокировки группы брандмауэр не меняет.

## Профиль и выход

| Действие | Куда ведёт |
|---|---|
| Сообщества | Discord, YouTube, Reddit, Telegram через `LinkPolicy` |
| Пригласить друга, личный кабинет, пополнить | Внешняя ссылка, тот же allowlist |
| Аккаунты | Страница настроек, главное окно не закрывается |
| Выйти | Модалка. Отмена — остаётесь. Подтверждение — снова панель входа |
| Крестик или Alt+F4 | `Platform.exit()` без вопроса про аккаунт |

Отдельного пункта «Сменить аккаунт» в `profile.fxml` нет. Старые абзацы README и `WINDOWS.md` его ещё упоминают.
