## Download and pause

The first download opens the install dialog: path, client size, free space. On live the folder cannot be changed (`canChangeFolder = false`). On mock it can. Confirm starts the download.

If another game is already downloading, the dialog is «Уже идёт другая загрузка» / «Сменить загрузку». Cancel does not switch the job.

Pause cancels the current generation and sets `Paused` from `pausedProgress`. Resume calls download again.

<span class="zone-badge live">live</span> When the client is not downloaded and the catalog does not allow a download (`canDownload` is false and no update is required), the button is disabled. The tooltip is «Загрузка этого клиента недоступна.» (`fork.live.no_download`).

<span class="zone-badge mock">mock</span> Progress is the `MockUpdateService` timer. `-Dlauncher.mockSpeed` multiplies it. «Запускать по окончании загрузки» does not start the game on mock: `startWhenDownloaded` is read only when `liveBackend` is true. Exit mode on mock stays never, even if settings say otherwise.

A failed download shows «Не удалось обновить клиент» and «Соединение оборвалось. Повторите. Версия клиента не менялась.» (`main.exception.update`). The dialog does not include a path.

## Verify, reinstall, delete

The **⋯** menu. Confirmation:

| Action | When it asks | Text |
|---|---|---|
| Verify | Game is running | «Игра запущена. Чтобы проверить файлы, её нужно закрыть.» Button «Закрыть и проверить» |
| Reinstall | Always | «Файлы игры будут удалены и загружены заново…» |
| Delete | Always | «Удалить файлы игры? Чтобы играть снова, их придётся скачать заново.» |

On live, verify compares the catalog and downloads only files that do not match. Exclusions and paths outside the client directory are left alone. Verify does not write the version file. Failure codes the dialog can show: `no_client`, `no_catalog`, `no_seeds`, `file_mismatch`, `no_session`, `io`. Title: «Не удалось проверить файлы». The client version does not change until verify finishes.

Reinstall and delete run only after confirm. An unsafe delete path is `unsafe_path` and nothing is removed. No catalog is `no_catalog` and nothing is removed. A finished delete returns to not installed. Finished verify and reinstall return to ready.

The game folder is not opened above `gameRoot`. Logs are separate: `%APPDATA%/EXBO/runtime/logs`.

Live download seeds are HTTPS only. See [Limitations](../../reference/limitations/).
