`ScreenshotTour` writes PNGs to the directory from `-Dlauncher.screenshots`. For zone that is `docs/screenshots/zone/`. `shadcn/` and copies at the root of `docs/screenshots/` sit beside it. These pages use `zone/`.

The site build does not put the file on GitHub Pages. `npm run dev` shows the frame. A published build keeps the path.

There is no tunnel frame after the loading cards, and no separate measurement of the 460×316 update window. `01_update_window.png` is the tour's update frame. This page does not claim that picture is 460×316.
