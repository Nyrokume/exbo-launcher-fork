The settings button opens one column. **ИГРА** (RAM), **ПОВЕДЕНИЕ**, **ОБНОВЛЕНИЕ**, and **ЯЗЫК** sit on that column. JVM, the tunnel, sensitivity, accounts, and localization replace the column. There is no graphics page. There is no sound page.

<ZoneShot file="zone/06_settings.png" caption="Settings column" />

Every change is saved at once.

## Memory

The scale runs from 2 GB up to the machine's memory, and never above 8 GB, in steps of 1 GB. The line «Выделено: N из M» and the scale captions use that ceiling: a 32 GB PC tops out at 8 GB. «Мало памяти останется системе» appears when the chosen value would leave the machine with less than 2 GB. Eight gigabytes on a 32 GB PC does not show it. The recommended value is half the memory and at most 6 GB, and it sits in the scale tooltip. Until the gigabytes are stored in settings, a JVM preset takes the generator's heap. After a choice, a preset click writes that heap.

On live the chosen gigabytes go into the launch (`InstalledGameLauncher`). On mock `MockSystemInfo` reports 16 GB and no game starts.

## Behavior

| Row | What is saved | Who reads it |
|---|---|---|
| Закрывать лаунчер | On game start / on game exit / never | Live only. On mock `ExitMode` stays never |
| P2P-загрузка | Always / except mobile / never | The settings file. The torrent does not read it. See [P2P later](../../network/p2p/) |
| Запускать игру по окончании загрузки | Switch | Live only. On mock a finished download does not start the game |
| Windows Defender | Switch | Disabled on live. Tooltip below |
| Анимации интерфейса | Switch | `Motion` at once. `-Dlauncher.animations` locks the row |
| Сворачиваться в трей | Switch | Written to the file. The window close calls `Platform.exit()`. Close has no tray branch |
| Запускать лаунчер при включении компьютера | Switch | Written to the file. Disabled on live |

On live, autostart and Defender cannot be toggled. The tooltip is «Здесь не применяется: автозапуск и Защитник Windows остаются у установленного лаунчера.» The Defender dialog does not open on a normal launch. F4 shows it, and only with `-Dlauncher.dev=true`.

## Update on this column

The **ОБНОВЛЕНИЕ** heading is the download and upload speed limit in KB/s. 0 means unlimited. It is not launcher self-update. Self-update is [Update fail-closed](../../getting-started/update/).

The bundle contains `settings.auto_update`. The form does not.

## Language

«Русский» and «English». The choice writes `language` and calls `switchLanguage`: the main screen is rebuilt and the open settings page stays.
