Файл `docs/CHANGELOG.md` нумерует pull request в `main`. Даты там по Екатеринбургу (UTC+5). Ниже сжатый пересказ, не замена файла.

## Не выпущено в файле истории

Окно входа ветки `redesign/login-socials`: высота по панели, логотип EXBO вместо заголовка, ссылки и ошибки на `-destructive-text`, подсказки полей до AA. Обои за окном входа пробовали и убрали. Пересчёт высоты только когда панель меняет раскладку (`AuthWindowRefitTest`).

Оболочка и туннель (#41): колонка **253 px** на 1024×640 и **220–340 px** по ширине окна, настройки на всю область контента, мок-каталог из classpath, отдельные карточки загрузки, ошибки и пустого списка. Окно обновления — **460×316** до показа.

Открытые PR поверх этого файла см. на страницах [окон](../../architecture/windows/) и [туннеля](../../settings/tunnel/).
