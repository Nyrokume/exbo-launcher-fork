## Регистрация на live

`ExboAuthService.register` возвращает `RegisterError.NOT_SUPPORTED`. Форма показывает «Этот лаунчер не создаёт аккаунт. Создайте его на сайте STALZONE.» Запроса регистрации в репозитории нет. Учётка создаётся на сайте STALZONE. Mock не менялся: имя не `taken`, почта не занята, возраст от 18 — аккаунт на моке создаётся.

## Самообновление

Любое предложение отклоняется как `unsigned`, пока нет публичного ключа релиза. Файл не пишется. Окно — «Обновление лаунчера отклонено: нет проверенной подписи.» Без предложения открывается вход. Окно обновления до показа — 460×316. Сертификата Authenticode в репозитории нет, установщик не подписывается.

## Каталог туннеля

Мок (`mockCatalog`, то есть не live) читает classpath: `servers-ru.json` и `servers.json`, включая NEA (`TYO`, `KOR`). За этим списком по HTTPS не ходит. Пулы `CLOUD-*` и адреса документации до строк не доходят. Затем проба оставляет только ответившие узлы. Live вызывает `TunnelCatalogs.fetch` по HTTPS-хостам региона. Редиректы не следуют. Новых адресов каталога страница не вводит.

## P2P и лимит скорости

Положения P2P и поля КБ/с пишутся в `settings.properties`. `SessionManager` их не получает. На торрент они не влияют.

## Семена клиента

`httpsWebSeeds` оставляет только HTTPS без userinfo. `http://` из списка семян выпадает. Пустой список семян на проверке файлов даёт `no seeds` и текст «Нет адресов загрузки, чтобы восстановить файлы.» Хосты учётки в `ExboHosts.credential` — три HTTPS. Рядом лежит `ExboHosts.cleartext` с `http://`. В запрос он не уходит: `exboBaseIsTrustedHttps` принимает только credential.

## Сессии

`sessions.json` на Windows хранит `EXBO_SESSION` как `dpapi1:` плюс base64, текущий пользователь. На системе без DPAPI новый токен в файл не пишется. `HKCU\SOFTWARE\EXBO` остаётся сырой строкой: иначе запрос сессии установленного лаунчера получил бы шифртекст. Окно установки и тихий шаг NSIS этот ключ не пишут и не удаляют.

## Чего на экране нет

Страниц графики и звука нет. Переключатели «в трей» и «запуск с компьютером» сохраняются. Закрытие окна идёт в `Platform.exit()` и трей не открывает. На live автозапуск и Защитник в форме заблокированы.

## Две установки

На live над полями входа стоят RU и EU. Нет папки `%APPDATA%\Exbo_East` — остаётесь на текущей установке, текст «EU-лаунчер не установлен…». На mock этой строки нет. Каталог JVM и языковой файл имён читаются из `%APPDATA%\EXBO`. Кнопка **Применить** на странице аккаунтов пишет `HKCU\SOFTWARE\EXBO`.

## Имена предметов

**Записать** на странице локализации меняет строки `item.*.name` в языковом файле клиента RU и кладёт копию в `%LOCALAPPDATA%\stalcraft-nyrokume\item-names.json`. Файла нет — кнопка выключена, строка «Языковой файл игры не найден».
