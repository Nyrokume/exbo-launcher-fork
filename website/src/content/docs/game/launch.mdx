## Скачать и пауза

Первое скачивание открывает модалку установки: путь, размер клиента, свободное место. На live папку менять нельзя (`canChangeFolder = false`). На mock можно. Подтверждение зовёт загрузку.

Если уже качается другая игра, модалка «Уже идёт другая загрузка» / «Сменить загрузку». Отмена ничего не переключает.

Пауза отменяет текущее поколение и ставит `Paused` с долей `pausedProgress`. «Продолжить» снова вызывает загрузку.

<span class="zone-badge live">live</span> Если клиент ещё не скачан и каталог не отдаёт загрузку (`canDownload` ложен, обновление не требуется), кнопка неактивна. Подсказка: «Загрузка этого клиента недоступна.» (`fork.live.no_download`).

<span class="zone-badge mock">mock</span> Прогресс — таймер `MockUpdateService`. Скорость множит `-Dlauncher.mockSpeed`. «Запускать по окончании загрузки» на mock игру само не стартует: `startWhenDownloaded` читается только при `liveBackend`. Режим выхода на mock зафиксирован как «никогда», даже если в настройках выбрано иное.

## Проверка, переустановка, удаление

Меню **⋯**. Подтверждение:

| Действие | Когда спрашивает | Текст |
|---|---|---|
| Проверить | Игра запущена | «Игра запущена. Чтобы проверить файлы, её нужно закрыть.» Кнопка «Закрыть и проверить» |
| Переустановить | Всегда | «Файлы игры будут удалены и загружены заново…» |
| Удалить | Всегда | «Удалить файлы игры? Чтобы играть снова, их придётся скачать заново.» |

На live проверка сверяет каталог и докачивает только несовпавшие файлы. Исключения и пути вне каталога клиента не трогает. Файл версии при проверке не пишет. Коды ошибки, которые диалог умеет показать: `no_client`, `no_catalog`, `no_seeds`, `file_mismatch`, `no_session`, `io`. Заголовок «Не удалось проверить файлы». Пока проверка не закончилась, версия клиента не меняется.

Переустановка и удаление идут только после подтверждения. Небезопасный путь удаления — `unsafe_path`, файлы не удалялись. Нет каталога — `no_catalog`, файлы не удалялись. Успешное удаление возвращает «не установлена». Успешные проверка и переустановка возвращают «готово».

Папка игры не открывается выше `gameRoot`. Логов это не касается: логи — `%APPDATA%/EXBO/runtime/logs`.

Семена загрузки на live — только HTTPS. Подробности на странице [ограничений](../../reference/limitations/).
