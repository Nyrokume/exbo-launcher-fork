Пока списка региона нет, над пустой областью не висит вечная строка «Загружаю группы…». Состояния каталога — отдельные карточки в колонке групп.

| Карточка | Заголовок | Что ещё |
|---|---|---|
| Загрузка | «Загружаю группы…» | «Список этого региона ещё в пути». Только пока список ещё в пути |
| Ошибка | «Не удалось загрузить группы» | «Повторите загрузку. Для этого региона нет сохранённой копии.» Кнопка «Повторить» |
| Пусто | «Группы ещё не загружены» | «Нажмите «Загрузить», чтобы открыть список.» Кнопка «Загрузить» |
| Список есть, рабочих узлов нет | «Нет рабочих серверов» | Это уже не карточка ожидания, а пустой разбор каталога |

«Повторить» и «Загрузить» заново запрашивают регион. Других кнопок на этих карточках нет.

<span class="zone-badge mock">mock</span> Когда `TunnelServices.mockCatalog` истинен (`!liveBackend`), открытый регион сразу показывает classpath-снимок. Карточка загрузки для этого снимка не остаётся.

<span class="zone-badge live">live</span> `mockCatalog` ложен. Список берёт `TunnelCatalogs.fetch`: HTTPS-хосты региона, редиректы не следуют, бюджет 10 с, таймаут источника 3 с. Пока ответ не пришёл, видна карточка загрузки. Ошибка сети — карточка с «Повторить».

Кадров «туннель после отдельной карточки» в `docs/screenshots/` нет. Здесь они не выдуманы.

Заголовок, панель «Измерить / Найти лучший / обновить / режим» и карточки групп стоят отдельными блоками. Колонки «До вас» и «Пинг» и переключатели блока остаются в карточке группы. На 900×580 и 1280×760 подписи помещаются целиком.
