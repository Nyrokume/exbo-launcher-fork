---
title: P2P позже
description: Режим P2P и лимиты скорости сохраняются. На SessionManager они не подаются.
---

В колонке **ПОВЕДЕНИЕ** три положения «P2P-загрузка»: «Всегда», «Кроме мобильных сетей», «Никогда». По умолчанию в модели — «Кроме мобильных сетей» (`P2pMode.EXCEPT_MOBILE`).

В блоке **ОБНОВЛЕНИЕ** два поля «Ограничение скорости»: загрузка и отдача, КБ/с, 0 — без ограничений. Подсказка: «В КБ/с, 0 — без ограничений».

Каждое изменение сразу пишет `p2pMode`, `downloadLimitKb` и `uploadLimitKb` в `settings.properties` (`ExboSettingsStore`). Импорт `settings.json` установленного лаунчера кладёт те же поля (`p2p`, `download`, `upload`).

На торрент это не влияет. `syncClientTorrent` создаёт `SessionManager`, стартует сессию и качает каталог. `p2pMode`, `downloadLimitKb` и `uploadLimitKb` в этот вызов не передаются. Отдельной доработки, которая подключает лимиты к сессии, в репозитории нет.

На mock загрузка вообще не открывает `SessionManager`: прогресс рисует `MockUpdateService`.

Строка `settings.auto_update` в пакете строк есть. В `settings.fxml` переключателя с этим текстом нет. Блок «ОБНОВЛЕНИЕ» на экране — только лимит скорости.
