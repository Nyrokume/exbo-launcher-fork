Пункт **Туннель** в настройках заменяет колонку лаунчера на всю область. Исходник поведения — `TunnelPage.kt` и комментарий `TunnelOverrides.kt`. Страница не описывает правила брандмауэра: на `main` выбор узла пишется как адрес Roxy, а не как скрипт firewall.

## Что на экране

Первая строка — регион: **RU**, **EU**, **NA**, **SEA**, **NEA**.

Вторая строка, слева направо:

- **Измерить** — замер открытого региона. Выбранный сервер и `overrides.json` не меняет;
- **Найти лучший сервер** — если свежего успешного замера нет, сначала измеряет. Затем записывает один узел с лучшим показателем режима. Без ответа и на лимите не выбираются. Исключённые группы в кандидаты не входят;
- **Обновить** — список заново. Сервер, которого не было в прошлом списке, остаётся скрытым, пока не ответит. Промах убирает узел из пула;
- меню режима: **Пинг**, **RTT клиента**, **RTT сервера**, **Стабильность**. Это список в стиле страницы, не системный combo.

Над строками — подписи колонок **До вас**, **До игры**, **Пинг**. Колонка, по которой ищет «Найти лучший», помечена. Стабильность тоже смотрит на пинг.

Группа — карточка: имя, число видимых узлов, справа замок **Исключить**. Замок сразу переписывает исключение группы в `overrides.json`, без отдельного подтверждения. Клик по имени группы измеряет только её.

Строка узла: замок (открыт, закрыт вместе с группой или лимит), точка «этот узел записала бы кнопка лучшего», имя, три числа. Клик по доступной строке записывает override этого региона. Закрытый, исключённый или на лимите узел не выбирается.

Пустые фигуры — `—`. Нет ответа — подпись в колонке пинга. Шкала в подсказках строк: до 50 мс, до 100, выше 100. Потери и скачки за час тоже в подсказке, не отдельным абзацем.

## Куда это пишется

Игра читает один флаг на регион: `-Droxy_address_override.<region>=host:port`.

Выбор и режим поиска лежат в `jvm_wrapper/overrides.json`. Последние 20 замеров узла — в `jvm_wrapper/cache/tunnel_stats.json` и сбрасываются через 24 часа. На live каталог — `%APPDATA%\EXBO\jvm_wrapper`. На mock стол временный, системный профиль Windows страница не трогает.

Запуск проверяет сохранённый адрес. Каталог при запуске заново не качается и узлы не пингуются.

:::note[Открытый PR #21]
Ветка `cursor/tunnel-settings-ui-4562` не влита. Там кнопка группы называется **Исключить группу** и после применения **Группа исключена**. Нажатие открывает подтверждение («Заблокировать N нод группы?» / «Вернуть N нод группы?»). Отмена ничего не пишет. Отдельный переключатель узла (красная дорожка — блок) меняет один id сразу, без диалога.

Строки без годного IPv4 скрыты. Пулы `CLOUD-*` отфильтровываются до замера и поиска. На `main` этого подтверждения и фильтра нет: исключение группы пишет файл сразу, как описано выше.
:::
