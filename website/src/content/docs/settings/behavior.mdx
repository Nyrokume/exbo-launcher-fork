Кнопка настроек открывает одну колонку. Блоки **ИГРА** (ОЗУ), **ПОВЕДЕНИЕ**, **ОБНОВЛЕНИЕ** и **ЯЗЫК** стоят на этой колонке. JVM, туннель, чувствительность, аккаунты и локализация заменяют её целиком. Отдельной страницы графики нет. Отдельной страницы звука нет.

<ZoneShot file="zone/06_settings.png" caption="Колонка настроек" />

Каждое изменение пишется сразу.

## Оперативная память

Шкала от 2 ГБ до памяти машины, но не выше 8 ГБ, шаг 1 ГБ. Подпись «Выделено: N из M» и деления шкалы считают этот потолок: на компьютере с 32 ГБ шкала идёт до 8 ГБ. Пометка «Мало памяти останется системе» появляется, когда выбранное значение оставляет машине меньше 2 ГБ. Восемь гигабайт на компьютере с 32 ГБ её не показывают. Рекомендуемое значение — половина памяти и не больше 6 ГБ, оно в подсказке шкалы. Пока гигабайты не записаны в настройки, пресет JVM берёт heap генератора. После выбора клик по пресету пишет этот heap.

На live выбранные гигабайты уходят в запуск (`InstalledGameLauncher`). На mock `MockSystemInfo` сообщает 16 ГБ, игра не стартует.

## Поведение

| Строка | Что сохраняется | Кто это читает |
|---|---|---|
| Закрывать лаунчер | При старте игры / при завершении игры / никогда | Только live. На mock `ExitMode` остаётся «никогда» |
| P2P-загрузка | Всегда / кроме мобильных / никогда | Файл настроек. Торрент не читает. См. [P2P позже](../../network/p2p/) |
| Запускать игру по окончании загрузки | Переключатель | Только live. На mock загрузка сама игру не стартует |
| Защитник Windows | Переключатель | На live выключен. Подсказка ниже |
| Анимации интерфейса | Переключатель | `Motion` сразу. `-Dlauncher.animations` блокирует строку |
| Сворачиваться в трей | Переключатель | Пишется в файл. Крестик окна вызывает `Platform.exit()`, ветки трея у закрытия нет |
| Запускать лаунчер при включении компьютера | Переключатель | Пишется в файл. На live выключен |

На live автозапуск и Защитник не переключаются. Текст подсказки: «Здесь не применяется: автозапуск и Защитник Windows остаются у установленного лаунчера.» Модалка Защитника в обычном запуске сама не открывается. Её показывает F4, и только при `-Dlauncher.dev=true`.

## Обновление на этой колонке

Заголовок **ОБНОВЛЕНИЕ** — это лимит скорости загрузки и отдачи в КБ/с. 0 значит без ограничений. Это не самообновление лаунчера. Самообновление — страница [Update fail-closed](../../getting-started/update/).

Строка `settings.auto_update` в пакете перевода есть. На форме её нет.

## Язык

«Русский» и «English». Выбор пишет `language` и вызывает `switchLanguage`: главный экран собирается заново, открытая страница настроек остаётся.
