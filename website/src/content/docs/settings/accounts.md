Пункт **Аккаунты** есть и в шапке настроек, и в меню профиля. Оба открывают одну страницу и не закрывают главное окно. Это не выход из аккаунта и не демо-логин.

## Что на карточке

Если сохранённых сессий нет, страница пишет «Нет сохранённых сессий».

Иначе каждая сессия — карточка:

- слева имя и, если в снимке есть непустой `EXBO_LOGIN`, строка «Логин: …»;
- бейдж **Текущая**, когда снимок совпадает с живыми значениями стола;
- справа иконка ключа, **Применить**, **Удалить**.

Ключ — не замок туннеля. Он открывает список значений снимка. Пустой снимок пишет «В снимке нет ключей». Карточка после сохранения не схлопывается: открытый ключ остаётся открытым, пока вы на странице.

Под списком поле «Имя сессии» и кнопка **Сохранить**. Она снимает текущие значения стола (`captureCurrent`). Пустое имя становится `session N`.

**Применить** пишет в стол план сессии и показывает «Сессия „…“ записана в реестр». **Удалить** убирает запись из `sessions.json` и показывает «Сессия удалена».

## Что именно применяется

`ExboSessions.applyPlan` отдаёт только `EXBO_AUTO_AUTH`, `EXBO_LOGIN` и `EXBO_SESSION`. Авто-вход при применении принудительно `true`. Другие значения снимка в реестр этой кнопкой не уходят.

На live файл — `%LOCALAPPDATA%\stalcraft-nyrokume\sessions.json`. Значение `EXBO_SESSION` в этом файле на Windows запечатано DPAPI (`dpapi1:` и base64, текущий пользователь). На диске нет открытого токена. Карточка и кнопка **Применить** видят уже открытый токен. `HKCU\SOFTWARE\EXBO` по-прежнему хранит сырую строку сессии: её читает установленный лаунчер RU и запрос `/auth?session=`. Кнопка пишет этот ключ и когда на входе выбран EU. Ключ `SOFTWARE\Exbo_East` эта страница не открывает. Это протокол EXBO, его не переносят в тело запроса. На системе без DPAPI новый токен в файл не пишется. На mock стол — временный каталог и `MemoryRegistry`: системный реестр Windows страница не открывает.

:::caution[Не путайте с демо-входом]
Mock-логин любого пароля живёт в `MockAuthService` и в реестр не пишет. Карточки аккаунтов пишут в стол `AppContext`. На витрине и в тестах стол временный.
:::
