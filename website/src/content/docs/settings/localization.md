title: Локализация
description: Поиск имён предметов и оружия и запись в языковой файл клиента.
---

Пункт **ЛОКАЛИЗАЦИЯ** в шапке настроек заменяет колонку. В меню профиля этого пункта нет. Список крутится внутри страницы, как туннель и чувствительность.

## Что на экране

Верхняя строка, слева направо: **Оружие**, **Предметы**, **Изменённые**, поле «Поиск», кнопка **Записать**. Подсказка кнопки: «Записать названия в языковой файл игры». Пока файла нет, кнопка выключена.

Строка списка: слева штатное имя, справа поле с подсказкой «Новое название». Пустой поиск ничего не находит — «Ничего не найдено». «Изменённые» оставляет строки, у которых уже есть сохранённое имя или несохранённая правка.

Под списком заметка. Пока файл читается — «Читаем названия…». Когда он прочитан — «Оружие: N. Предметы: M.». После записи — «Записано: N», где N — число сохранённых переименований. Ошибка записи — «Не удалось записать названия». Файла нет — «Языковой файл игры не найден».

## Откуда имена

Страница читает `modassets/assets/stalker/lang/<язык>.lang` рядом с `options.json` клиента в `%APPDATA%\EXBO\runtime\stalcraft`. Язык берётся из `"language"` в `options.json`. Принимаются `ru`, `en`, `es`, `fr`, `ko`. Другое значение и отсутствие файла настроек дают `ru`.

В список попадают строки `item.*.name`. Оружие — `item.wpn.*` и `item.melee.*`. Остальные такие ключи — предметы. Имя обрезается до 120 символов, переводы строк выкидываются.

## Куда пишется

**Записать** меняет только затронутые ключи. Пустое поле или штатное имя снимает переименование и, если в файле ещё лежит свой текст, возвращает прежнее имя. Остальные строки файла, включая переводы строк, не трогаются.

Копия лежит в `%LOCALAPPDATA%\stalcraft-nyrokume\item-names.json` (если переменной нет — `AppData\Local` в профиле пользователя). После скачивания, проверки или переустановки клиента `restoreAfterUpdate` читает свежий lang-файл и возвращает сохранённые имена. Ключ, которого в новом файле нет, из копии выпадает. Новое штатное имя становится тем, от чего считается правка.

На mock языкового файла установленного клиента нет, заметка остаётся «Языковой файл игры не найден».
