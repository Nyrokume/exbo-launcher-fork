# История изменений

Форк только визуального слоя лаунчера EXBO. Номера — pull request'ы в `main`, даты по Екатеринбургу (UTC+5).

## Не выпущено

- **Оболочка и страница туннеля** (#41). На 1024×640 боковая колонка остаётся **253 px** и дальше следует за шириной
  окна (**220–340 px**). Логотип масштабируется вместе с ней, подпись игры не вылезает из строки. Колонка настроек
  заполняет область контента: потолок **820 px** снят, на 1280 px туннель занимает всю ширину. Заголовок, панель
  действий и карточки групп — отдельные блоки. Колонки «До вас» / «Пинг» и переключатели блока на месте; на 900×580
  и 1280×760 подписи помещаются целиком. Мок читает каталог из classpath (`servers-ru.json`, `servers.json`, фикстура
  NEA) и за списком в сеть не ходит. Загрузка, ошибка и пустой каталог — отдельные карточки; ошибка даёт
  «Повторить». «Отмена» у подтверждения блокировки группы брандмауэр не меняет.
- **Живая регистрация и самообновление** (#35). На live `ExboAuthService.register` возвращает
  `RegisterError.NOT_SUPPORTED`. Форма показывает `fork.reg.error.unavailable`: «Этот лаунчер не создаёт
  аккаунт. Создайте его на сайте STALZONE.» Запроса регистрации в репозитории нет. Mock не менялся: любое
  имя, кроме занятого, и возрастной гейт по-прежнему создают аккаунт. Любое предложение обновить лаунчер
  отклоняется как `unsigned`, пока не закреплён публичный ключ релиза (`decideLauncherUpdate` /
  `stageLauncherUpdate` в `LauncherUpdateGate.kt`): файл не пишется. Окно показывает `auth.update.rejected`:
  «Обновление лаунчера отклонено: нет проверенной подписи.» Без предложения проверка заканчивается и
  открывается вход.
- **Мастер установки NSIS** (#36). Установка для текущего пользователя в `%LOCALAPPDATA%\LauncherFork`, без UAC.
  Путь всегда заканчивается на `\LauncherFork`, в том числе при тихой установке `/S /D=...`. SHA-256 каждого
  файла сверяется до замены и после копирования: несовпадение, пропавший файл или нет PowerShell останавливают
  установку (код 3), длины файла недостаточно. Чужой `runtime` или `app` без маркера `.launcherfork-install`
  отклоняется (код 2). `HKCU\SOFTWARE\EXBO` (`EXBO_SESSION`), каталог игры и `%APPDATA%\EXBO` не пишутся и не
  удаляются. Ярлык с тем же именем меняется, только если указывает на этот `LauncherFork.exe`. В «Приложениях
  и возможностях» издатель EXBO и имя EXBO Launcher, подписи Authenticode нет (сертификата в репозитории нет,
  это TODO): форк неофициальный, и без подписи его легко спутать с официальным ExboLauncher.
- **Компактное окно входа** (#20, ветка `ui/auth-compact`). Окно панели входа **460×506** (ширина та же; раньше
  потолок 460×700 занимала и панель входа). Блок логотипа EXBO с фиксированными отступами, без растягивания по
  высоте. Строка Steam / Epic («Или войти через») скрыта (`visible="false"`, `managed="false"`) и места не
  занимает. Код из письма в покое **460×438**, с ошибкой **460×526**; Google Authenticator (TOTP) в покое
  **460×444**, с ошибкой **460×532**. Регистрация и возраст по-прежнему держат полное окно **460×700**.
- **Компактное окно обновления лаунчера.** `update_panel.fxml` без фиксированной высоты и без растягивания верхней
  карточки: окно **460×316** (область панели **460×284**) в ru и en. Пустая строка ошибки места не занимает; текст
  ошибки поднимает окно. Пол pre-main — **280**.
- **Окно входа** (ветка `redesign/login-socials`). Компактное окно по высоте панели, логотип EXBO вместо заголовка,
  читаемая неактивная кнопка, красные ссылки на `-destructive-text`. Красный текст ошибки и поля с ошибкой в тёмной
  zone был `-error` 4.41:1, теперь `-destructive-text` (5.5:1, рамка осталась `-error`); подсказки в пустых полях
  `-placeholder` 2.97:1 → AA в zone и zone-light (`SettingsContrastTest`). Высота окна пересчитывается только когда
  панель меняет раскладку, а не после каждого кадра (`AuthWindowRefitTest`). Обои за окном входа пробовали и убрали:
  без картинки окно смотрится чище.
