- **Меню профиля, внешние ссылки и новые обои.** «Профиль» → «Личный кабинет» (открывает `https://stalzone.com/user`
  в браузере), пункт «Пригласить друга» → `https://stalzone.com/referral`; «Сменить аккаунт» убран — назад во вход
  только через «Выйти» с подтверждением. Лицензия и политика конфиденциальности в модалке лицензии открывают PDF на
  `exbo.games` (`ExternalLinks` + `LinkOpener`); в `LinkPolicy` добавлен хост `exbo.games` (рядом с `exbo.net`).
  Пять новых обоев `07…11.jpg` (всего 11; `11.jpg` апскейл с 600×338), `-Dlauncher.wallpaper=1..11`.
  `RegisterController.onDocLink` по-прежнему показывает `fork.not_available` — проводку `ExternalLinks.LICENSE` /
  `PRIVACY` там оставить Front.end.master.
- **Режим витрины** (`-Dlauncher.showcase=true`, `./gradlew showcase`). Looping-презентация редизайна с
  мок-данными и анимациями: главное окно и обои → четыре темы → баннер → настройки → меню профиля /
  «Сообщества» → загрузка / пауза → окно входа и регистрация → вход (`player`). Ничего не сохраняет
  (настройки только в памяти, `-Dlauncher.settingsFile` игнорируется, `wallpaper.last` не пишется). Общие
  шаги с screenshot-туром: `TourActions` / `StepQueue`. Подпись шага в полосе заголовка (не в nav-ряду),
  размер окна `launcher.showcase.size`, кадры `launcher.showcase.stills`, выход по Escape или после
  `launcher.showcase.loops`. Документация: `docs/SHOWCASE.md`. Тесты: `ShowcaseTest` (маршрут, разбор
  размера, файл настроек нетронут).
- **Анимации интерфейса.** Общий помощник `ui/motion/Motion`: токены 120 / 200 / 280 мс, ease-out
  `SPLINE(0.2, 0, 0, 1)`, сдвиги не больше 12 px, нажатие — масштаб 0.97; никаких пружин и зацикленных эффектов.
  Анимируются: появление окна (контент проявляется, без белой вспышки), смена панелей окна входа и пересборка
  главного экрана при смене языка (кроссфейд снимком), смена темы «Тёмная / Белая» (кроссфейд), обои (проявление при
  загрузке, кроссфейд при смене картинки, опционально медленный зум `-Dlauncher.wallpaper.drift=on`), текст игры
  (fade + 8 px вверх; выравнивание по строке из #15 держится в конце анимации), фон строки игры при наведении и
  маркер выделения, ИГРАТЬ (нажатие 0.97, подсветка при наведении), меню профиля / «Сообщества» / «⋯» (fade + 6 px,
  закрытие быстрым fade), модалки (затемнение + карточка 98 % → 100 % и 8 px), главная ↔ настройки (кроссфейд),
  переключатели (бегунок скользит), полосы загрузки (плавно, но 0 % и 100 % сразу). Новая анимация на узле
  останавливает предыдущую и продолжает с текущих значений: узел всегда приходит в правильное конечное состояние, клики
  во время анимации не теряются. Прогресс защищён от NaN / ∞ / отрицательных значений и > 1. Переключатель
  «Анимации» в «Поведении» (сохраняется: `animations=on|off` в `settings.properties`), `-Dlauncher.animations=off`
  важнее настройки; чтобы восемь строк «Поведения» по-прежнему помещались на 900×580 без прокрутки, строки с
  переключателями стали 30 px (сегментные — 34 px, как были), промежутки между блоками и внутри карточки RAM чуть
  меньше (шкала RAM в стиле EXBO не менялась). В тестах анимации выключены (`build.gradle.kts`), автотур выключает
  их сам — скриншоты без промежуточных кадров (скриншоты в `docs/` не переснимались).
  Тесты: `MotionTest` (токены, выключатель, мгновенное конечное состояние, быстрые переключения игр / меню / экранов,
  прогресс, выравнивание баннера после анимации).
- **Описание игры на линии своего пункта меню** (#15). Верх букв заголовка STALZONE стоит на верхнем крае выбранной
  строки игры в колонке слева (там же, где красный маркер), а не выше неё. Отступ не число в CSS: `MainController`
  ставит верх слота `centerPane` по положению строки и метрикам шрифта заголовка, поэтому он держится во всех темах,
  на 900×580 – 1920×1080 и после смены логотипа; строка навигации не меняется, прокрутка текста в маленьком окне и
  строка статуса — как раньше. Тест: `GameBannerTest` (±2 px, все темы и размеры). Скриншоты главного окна пересняты.
- **Обои главного окна** (#14). За главным окном, как в оригинальном лаунчере, — скриншот STALZONE: шесть картинок
  (`ui/wallpapers/01…06.jpg`, до 1920 px, JPEG ~82, манифест `wallpapers.txt` с точкой фокуса и тоном). При каждом
  запуске случайные, но не те же, что в прошлый раз (`wallpaper.last` в `~/.launcher-fork/settings.properties`),
  фиксированные — `-Dlauncher.wallpaper=1..6` (такой выбор не сохраняется и не затирает `wallpaper.last`); выбор один на запуск (`Wallpapers.current`), окно входа сможет взять
  ту же картинку через `WallpaperLayer.forCurrent`. Cover-кадрирование при любом размере и разворачивании, фоновая
  загрузка только выбранной картинки, запасной однотонный фон. Читаемость: скримы `-wallpaper-*` в токенах всех
  четырёх тем (тёмные в тёмных темах, белый в zone-light), `WallpaperContrastTest` проверяет худший случай
  (95-й перцентиль) для каждой картинки и темы. Смена темы больше не стирает другие ключи `settings.properties`.
  Скриншоты всех тем пересняты автотуром (обои `03`).
