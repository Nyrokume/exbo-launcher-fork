# STYLE-ZONE: тема `zone` (тёмная, плоская, красный акцент)

Включается так: `-Dlauncher.theme=zone`. Файл с токенами: `src/main/resources/dev/launcherfork/ui/style/theme-zone.css`.
Он подключается к Scene сразу после `theme.css` (`Theme.apply`), поэтому переопределяет только значения токенов.
Разметка и CSS компонентов ссылаются на токены, литеральные цвета в них не пишутся.
Цвета сняты с эталонных скриншотов (лаунчер STALCRAFT, 1598×1000) и с внутриигрового UI.

## Токены

Имена токенов те же, что в `theme.css`. Поэтому компонент, сверстанный на токенах, работает во всех трёх темах
(`exbo`, `shadcn`, `zone`).

| Токен | zone | Где используется |
|---|---|---|
| `-background` | `#0e0e0e` | фон окна и контента |
| `-foreground` | `#ffffff` | заголовки, основной текст |
| `-card` | `rgba(16,16,16,.82)` | полупрозрачные тёмные панели: карточки новостей, попапы, тултипы |
| `-card-foreground` | `#e6e6e6` | текст на панелях |
| `-popover` / `-popover-foreground` | `rgba(14,14,14,.94)` / `#e6e6e6` | контекстное меню, тултип |
| `-primary` | `#e93046` | красный акцент: залитая кнопка, активные сегменты, точка радио/тумблера, индикатор активного пункта, ползунок прокрутки |
| `-primary-foreground` | `#ffffff` | текст на красном |
| `-primary-hover` | `#ff3f56` | hover залитой кнопки |
| `-secondary` / `-secondary-foreground` | `#1a1a19` / `#ffffff` | заливка контурной кнопки «Играть» |
| `-muted` | `#1b1b1b` | заливка полей ввода |
| `-muted-foreground` | `#5e5e5e` | единицы (KB/s), подсказки, статус, ссылки в шапке |
| `-accent` / `-accent-foreground` | `rgba(255,255,255,.06)` / `#ffffff` | hover-подсветка пунктов |
| `-border` | `#353535` | кольцо радио, неактивные сегменты, рамки панелей |
| `-ring` | `#e93046` | фокус: красное подчёркивание поля |
| `-destructive` | `#e93046` | ошибки |
| `-input` / `-input-foreground` / `-placeholder` | `#1b1b1b` / `#fff` / `#5e5e5e` | залитые поля (авторизация) |
| `-titlebar` / `-titlebar-foreground` | `#0b0b0b` / `#ffffff` | полоса заголовка окна, глифы «свернуть/развернуть» |
| `-window-close` / `-window-close-hover` | `#d83e3e` / `#ff4a4a` | крестик (красный и в покое) |
| `-sidebar` | `#0f0f0f` | левая колонка |
| `-divider` | `#1a1a19` | вертикальная линия между колонкой и контентом |
| `-divider-light` | `rgba(255,255,255,.12)` | тонкие светлые разделители в панелях (внутриигровой UI) |
| `-heading-rule` | `#ffffff` | подчёркивание заголовка раздела (градиент в прозрачность вправо) |
| `-segment-off` | `#353535` | неактивный сегмент полосы RAM |
| `-track` | `#2d2d2c` | дорожка прогресса, рамка кнопки-иконки |
| `-icon` | `#8e8e8e` | глифы маленьких кнопок (инструменты) |
| `-scrim` | `rgba(0,0,0,.55)` | затемнение под оверлеем |

Остальные токены из `theme.css` (`-text-*`, `-overlay*`, `-shadow*`) тоже переопределены, чтобы старые экраны
не выпадали из палитры.

JavaFX умеет looked-up значения только для цветов. Поэтому радиусы, отступы и шрифты задаются группами селекторов,
а не переменными. Радиус в `zone` везде 0. Исключение — сегменты полосы RAM: на эталоне у них скруглённые торцы.

## Типографика

| Роль | Семейство (имя для JavaFX) | Кегль | Где |
|---|---|---|---|
| Вордмарк EXBO | `Oswald SemiBold` (`.font-display-strong`) | 64 | логотип в колонке (текстом, без картинки) |
| Hero, заголовок раздела | `Oswald` (`.font-display`), UPPERCASE | 46 | «ДОБРО ПОЖАЛОВАТЬ», «ИГРА», «НОВОСТИ» |
| Пункт меню, кнопка «Играть» | `Roboto` | 19–20 | «STALCRAFT: X», «Настройки», «Играть» |
| Подпись настройки, вариант | `Roboto` | 16 | «Оперативная память», «При старте игры» |
| Текст описания | `Roboto` | 13 | описание игры |
| Мелкая подпись CAPS | `Roboto Medium` (`.font-bold`), 10–11, UPPERCASE, `-muted-foreground` | 10–11 | подписи над значениями (стиль внутриигровых панелей) |
| Статус, единицы | `Roboto` | 11–14, `-muted-foreground` | «Готово к запуску», «KB/s» |

Шрифты лежат в `ui/style/font/`: Oswald и Roboto, обе SIL OFL 1.1, лицензии в `OFL-Oswald.txt` и `OFL-Roboto.txt`.
В этой теме Oswald заменяет коммерческий Europe. Регистрирует их `Theme.zoneFonts`.

## Компоненты

Классы ниже определены в CSS компонентов новой раскладки и используют только токены.

- **Основная кнопка** (`.btn-primary`): заливка `-primary`, текст `-primary-foreground` в Oswald UPPERCASE,
  без радиуса, hover `-primary-hover`. Пример — «ВОЙТИ».
- **Контурная кнопка со скобками** (`.btn-bracket`): заливка `-secondary`, тонкая рамка `-track`, по углам
  белые уголки-скобки (4 L-образных штриха длиной ≈10 px, 2 px). Пример — «Играть», «СОЗДАТЬ БОЙ».
- **Радио** (`.radio-button`): кольцо Ø28, обводка 2 px `-border`, без заливки. Выбранное — красная точка Ø16
  (`-primary`) в кольце. Подпись Roboto 16, отступ 12 px.
- **Тумблер** (`.toggle-dot`, CheckBox): выглядит как то же кольцо с точкой, справа в строке настройки.
  Включён — красная точка, выключен — пустое кольцо.
- **Сегментная полоса** (`SegmentedBar`, `.segmented-bar`): 9 сегментов, высота 15, зазор 3 px, скруглённые
  торцы. Активные — `-primary`, неактивные — `-segment-off`. Значение (например, `3323MB`) мелким кеглем 9 по
  центру последнего активного сегмента. Клик или перетаскивание меняет значение.
- **Подчёркнутое поле** (`.underline-field`): без заливки, значение белое, единица (`KB/s`) `-muted-foreground`.
  Подчёркивание 1 px `-border`, а при фокусе `-ring`. Справа иконка (скачивание или отдача).
- **Заголовок раздела** (`.section-header`): Oswald 46 UPPERCASE, под ним линия 1 px с градиентом от
  `-heading-rule` в прозрачный вправо, ширина ≈410 px.
- **Пункт колонки** (`.sidebar-item`): иконка 24 + текст Roboto 19. Активный — красная полоса 4 px у левого
  края (`-primary`). Hover — `-accent`.
- **Карточка новости** (`.news-card`): картинка 295×165 без рамки, внизу полупрозрачная панель `-card` с
  заголовком. Колонка прокручивается, справа узкий красный ползунок (`-primary`) без дорожки.
- **Полоса заголовка окна** (`.title-bar`): высота 28, `-titlebar`. Справа «свернуть», «развернуть» и
  «закрыть» по 30 px. Крестик `-window-close`, при наведении `-window-close-hover`.
- **Панели в стиле игры** (`.panel`): фон `-card`, рамка 1 px `-divider-light`. Внутри мелкие CAPS-подписи
  над значениями, разделители 1 px `-divider-light`. Сегментные вкладки — активная светлее (`-accent`).
